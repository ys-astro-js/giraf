# UI 정돈 검증 항목

구현 전 작성. 기존 작업·파일·계산은 유지하며 아래 사용자 동작을 확인합니다.

- 1280×720 파일 선택: 목록에 6행 이상, 하단 적용/취소 노출. 검색·유형·범위 선택·여러 폴더 선택을 유지합니다.
- 390×844 및 중간 너비: 경로/긴 파일명으로 외부 가로 넘침이 없고 이름 클릭 후 미리보기가 보이며 닫아도 선택을 유지합니다.
- 검색 결과 없음/빈 폴더/실패가 구분되고 폴더 로딩 실패 후 같은 경로로 재시도할 수 있습니다.
- 단일 영상은 제목/저장 중복 없이 첫 화면에 전체 맞춤 영상을 표시합니다. 비교 A/B 선택 및 공통 범위가 유지됩니다.
- 방향키로 FITS 픽셀 이동, Shift+방향키 큰 이동, 좌표 입력, 경계/소수/빈 값 거절. 조사 위치 선택 모드에서는 Enter/선택 버튼에서만 적용합니다.
- 영상 교체 중 늦은 픽셀 응답이 새 영상에 나타나지 않습니다. 범위의 표시 정밀도를 줄여도 미편집 값의 실제 정밀도는 유지합니다.
- 선택 노드 변경, 패널 크기 변경, 재개방에서 노드 제목이 보입니다. 드래그·연결·전체 보기·사용자 확대는 유지됩니다.
- 초기 API 실패는 짧은 오류와 재시도 버튼으로 복구합니다.
- ccdtype 빈 값 표시는 짧게 하고 저장되는 빈 문자열은 그대로 유지합니다. 내부 구현을 해명하는 설명 문단은 추가하지 않습니다.
- 모달 Escape/초점 복귀 및 닫기 이름, 라이트/다크의 초점 표시를 확인합니다.


## 확인 결과

- Bun 관련 회귀 테스트 46개 통과(이번 변경 전 작성한 7개 포함), TypeScript 및 프로덕션 빌드 통과.
- 1280×720 파일 선택 목록 약 8행, 하단 버튼 노출. 390×844에서 파일명 줄바꿈·미리보기·5개 선택 보존 확인.
- 900×768 A/B 비교 및 같은 범위 전환 확인. 390×844 영상과 좌표 도구의 외부 가로 넘침 없음.
- 실제 FITS X1024/Y1024=4846 ADU, 방향키 위 이동 Y1025=4880 ADU 확인. Shift+오른쪽 X1034 이동 확인.
- API 중지 후 초기 오류와 다시 시도 버튼 표시, 재시도 후 로딩 상태 진입 확인. 최종 빌드의 정상 초기 로딩 확인.
- 선택한 작업 보기에서 ccdproc 노드가 가시 영역 안으로 이동함을 확인.
- layout detector 0건. 기존 tests/ui/workbench.test.ts의 전역 글꼴 크기 금지 검사는 이번 수정 전부터 존재한 App.tsx의 text-sm과 index.css의 크기 정의에 걸립니다. 이 기존 검사와 현재 DESIGN.md 사이의 불일치는 이번 변경에서 수정하지 않았습니다.
- 전체 스크린리더·모든 브라우저·200% 확대·실제 IRAF 재계산은 검증하지 않았습니다. 과학 데이터와 실행 설정은 변경하지 않았습니다.
