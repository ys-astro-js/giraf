# 노드 정돈 인수 조건 — 구현 전 작성

- 결과 탭에서 다른 노드의 제목/빈 곳을 선택하면 결과 탭을 유지합니다. 설정 탭도 동일합니다.
- 연결 중이 아닌 입력 행 클릭: 해당 노드를 선택하고 설정 탭에서 그 입력의 편집기를 펼쳐 초점을 이동합니다. 같은 입력 재클릭도 동작합니다. 비활성 보정 입력은 보정 스위치로 이동하며 값을 자동 변경하지 않습니다.
- 출력 선택 즉시 모든 호환 입력이 연결 대상으로 표시됩니다. 다중 입력 노드의 정확한 행을 한 번 클릭하면 해당 역할만 연결/교체합니다. 다른 입력은 보존합니다.
- 출력 드래그를 입력 행에 놓으면 그 역할에 바로 연결합니다. 파일 드롭도 역할을 유지합니다. 비호환 행은 연결하지 않으며 자기 자신·순환·종류·개수 검사는 유지합니다.
- Enter/Space 입력 선택과 Escape 취소를 지원합니다. 연결 후보와 hover를 구별하며 색 외에 연결/교체 문구가 보입니다.
- 결과 보기 버튼은 없고 완료·실패·실행 전 상태가 출력과 같은 하단에 있습니다. 영상 수와 전체 결과 파일 수를 구분합니다. 입력 역할의 중복 기술 키와 연결선 텍스트는 정리하되 접근성 이름은 유지합니다.
- 연결 시작/취소/성공/오류에서 안내 영역 높이와 노드 화면 좌표가 변하지 않습니다.
- 1280×720 및 390×844에서 카드·연결점 정렬, 긴 이름 생략, 상세 설정 접근, 탭 유지, 캔버스/상세 전환, 가로 넘침을 확인합니다.
- 기존 관련 회귀 테스트, TypeScript와 빌드, layout detector를 실행합니다. 실제 IRAF 계산은 변경하지 않습니다.

## 확인 결과

- 관련 회귀 테스트 50개, TypeScript, 프로덕션 빌드 통과. layout detector 0건.
- 전체 UI 검사 55개 통과, 기존 전역 typography 검사 1개 실패. 규칙 변경 없음.
- 결과 탭에서 다른 노드 선택 후 결과 탭 유지 확인.
- 데스크톱 zero 및 모바일 dark 입력 클릭으로 편집기 펼침과 source-zero/source-dark 초점 확인.
- 다중 입력 ccdproc의 zero 클릭 1회 및 dark 직접 드래그로 동일 출처 교체 완료. 기존 세 입력 연결 보존.
- 연결 시작/완료 전후 노드 좌표 동일. 연결점과 입력 행 중심 차이 1px 미만.
- Enter 연결 시작, 안내의 취소 버튼에서 Escape 취소 확인.
- 1280×720, 390×844 화면 확인. 모바일 문서 가로 넘침 없음.
- 실제 IRAF 실행, 파일 드롭, 비활성 입력 fallback의 브라우저 검증은 수행하지 않았으며 후자의 경로는 소스로 확인했습니다.

## 연결 미리보기 수정 인수 조건 — 구현 전 작성

- 연결 중 호환 입력 hover/키보드 초점: 해당 입력 연결점까지 강조색 점선 곡선이 붙고 왼쪽 점도 강조색이 됩니다. 다른 입력으로 이동하면 새 입력으로 옮겨갑니다.
- 기존 연결 대상은 미리보기 중 기존 선을 흐리게 하여 새 연결 경로를 식별할 수 있습니다. hover만으로 저장된 연결은 바뀌지 않습니다.
- 출력 드래그 중에도 포인터 캡처와 무관하게 입력 행을 감지하고 같은 미리보기를 표시합니다.
- 입력을 벗어나거나 비호환 입력으로 이동하거나 Escape 취소/연결 완료 시 강조가 남지 않습니다.
- 입력의 ‘연결/교체’ 설명과 점 구분자를 제거합니다. 완료는 하단 체크 아이콘이며 접근성 이름과 tooltip으로 완료를 제공합니다. 실패·실행 중 상태는 구별을 유지합니다.

## 설명 없는 연결 모드 — 구현 전 작성

- 연결 안내 줄과 예약 공간이 없습니다. 연결 시작/종료는 캔버스 위치를 바꾸지 않습니다.
- 시작한 출력점은 강조색의 취소 아이콘으로 바뀌며 재클릭으로 취소합니다. Escape/빈 캔버스 취소도 유지합니다.
- 호환 입력점은 강조색 테두리로 후보를 표시하고 hover 시 강조색으로 채워지며 점선이 해당 입력에 붙습니다. 클릭 연결 중에도 점선이 포인터를 따라갑니다.
- 스크린리더용 연결 상태 안내와 오류 알림은 유지합니다. 화면에 일반 연결 안내 문장을 표시하지 않습니다.

## 제목 편집 버튼 — 구현 전 작성

- 평상시 오른쪽 헤더에 제목/설명과 연필 버튼만 표시하고 입력란은 숨깁니다. 이름이 다를 때 명령 식별자만 보이며 ‘원본 명령’ 라벨은 없습니다.
- 연필 클릭으로 두 입력란이 열리고 제목에 초점이 갑니다. 체크 버튼/Enter로 한 번에 저장, X/Escape로 변경을 버립니다. 한글 조합 중 Enter는 저장하지 않습니다.
- 편집 중 다른 노드 선택 시 미확정 편집은 버리고 새 노드의 정보가 표시됩니다. 빈 제목 저장은 명령 이름으로 복원합니다. 캔버스에서 편집할 수 없습니다.
