# 독립 저장소 구성 (2026-09-19)

- GIRAF 위치: `~/Documents/Astronomy/giraf`.
- 프론트엔드 `web/`, 백엔드 `giraf/`, 테스트, 문서, 도구 설정, 워크플로우 및 로컬 실행 상태를 이동했습니다. 미커밋 프론트엔드 변경도 포함했습니다.
- Python 배포 프로젝트와 내부 패키지 이름은 `giraf`입니다.
- 첫 실행의 기본 탐색 폴더는 프로젝트 루트입니다. 저장된 작업 상태의 관측 원본 경로는 유지했습니다.
- 이전 저장소에는 강의 노트, 관측 원본 및 기존 Git 이력이 남습니다. GIRAF는 기존 루트·web Git 이력을 상속하지 않는 단일 저장소입니다.
- 이전 저장소의 마이그레이션 백업에 기존 두 Git 저장소와 이동 전 JSON 메타데이터를 보관했습니다.
- 실행 파일은 그대로 이동하고, JSON의 이동 대상 경로와 존재하는 파일의 경로 기반 식별자를 갱신했습니다. 실행 로그·명령 파일의 과거 기록은 유지했습니다.
- 작업 상태에 원래부터 삭제된 실행 파일 및 이전 Codex worktree 경로가 남아 있습니다. 분리 과정에서 과거 파일을 복원하거나 기록을 삭제하지 않았습니다.
