# IRAF 설정창 단순화 인수 조건

구현 전 작성. Operate. 기존 실행 값·연결·출력·사용자 설명을 보존합니다.

- 기본 inspector에는 task별 주요 입력·출력·파라미터를 표시하고 전체 설정은 넓은 Dialog로 엽니다.
- 전체 검색은 task·전처리·pset·package의 원문 이름과 도움말을 검색합니다. 변경값 필터와 함께 사용할 수 있으며 비활성 종속 값도 찾을 수 있습니다.
- 같은 이름의 pset 파라미터는 별도 ID와 변경 경로를 유지합니다. 열기·닫기·검색은 값을 지우거나 실행 payload를 변경하지 않습니다.
- 주요 목록에 없는 입력은 연결되었거나 명시적으로 요청되면 기본 화면에서 접근할 수 있습니다. 모든 입력·출력은 전체 편집기에서 접근할 수 있습니다.
- 원문 식별자가 주 라벨입니다. 필드 설명은 입력 바로 아래에 항상 표시하고 aria-describedby로 연결합니다. 필수 항목은 라벨의 별표로 한 번만 표시하며 aria-required를 유지합니다.
- 브라우저에서 desktop/mobile Dialog 폭·스크롤·긴 이름·검색·변경값·Escape·초점 복귀, 입력/pset 편집 후 유지와 복구를 확인합니다.
- TypeScript·관련 UI 회귀 테스트·프로덕션 빌드와 layout detector를 확인합니다. 실제 IRAF 계산은 변경 범위 밖입니다.

검증 결과: UI 테스트 110개 통과, TypeScript와 프로덕션 빌드 통과, layout detector 0건, diff 공백 검사 통과. 실제 브라우저에서 데스크톱 및 390×844 편집창, 전체 검색(order 및 ccdred.pixeltype), 변경값 필터, 원래 값 복원, readaxis 선택 메뉴, Escape 닫기 및 트리거 초점 복귀를 확인했습니다. 가로 넘침과 편집창 내부 중복 ID가 없었습니다. 개발 서버의 기존 Origin 거부 알림 때문에 서버 저장 완료를 검증했다고 주장하지 않습니다. 실행 payload 보존은 회귀 테스트로 확인했으며 IRAF 계산은 실행하지 않았습니다.

- 기본 설정과 전체 설정에서 텍스트 입력·선택창은 라벨 → 입력 → 설명의 세로 순서로 표시합니다. 스위치는 라벨과 같은 줄 오른쪽에 두며, 설명은 그 줄 아래에 표시합니다. 이 규칙은 화면 폭에 관계없이 유지합니다. 검색 도구 모음의 필터는 폼 필드와 구분합니다.
