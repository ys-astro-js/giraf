# 영상 뷰어 레이아웃 검증

구현 전 작성.

- 1280×720: 파일명·복귀·영상/헤더·파일 동작이 상단 한 줄. 이미지 위에 독립 도구 행 없음.
- 영상 영역은 상단 바를 제외한 높이를 사용. 확대·표시·비교·좌표·통계 동작은 오른쪽 도구 영역 안에 배치.
- 390×844: 이미지는 화면 높이 우선. 영상 도구 버튼에서 도구 영역을 열고 닫을 수 있고 숨겨진 도구는 키보드 초점 대상이 아님.
- 헤더 전환·저장·입력 재사용·복귀와 A/B 비교·좌표 조사 기능을 유지.
- 긴 파일명으로 상단 행이 늘어나지 않으며 전체 이름을 확인 가능.


## 결과

- 1280×720에서 상단 56px 한 줄, 영상/도구 작업면 높이 약 620px. 영상 작업면 높이는 유지했으나, 기존 확인에서는 내부 탭 줄바꿈을 놓쳤습니다.
- 390×844에서 도구 패널 열기/닫기 및 화면 내부 배치 확인. 외부 가로 넘침 없음.
- 좌표 X1024/Y1024에서 4846 ADU, 영상/헤더 전환 확인. 브라우저 오류 없음.
- 후속 수정: 범위·통계·프로파일을 고정 3열로 배치하고 표시·통계 펼침 버튼을 제거했습니다. 확대 버튼은 4열, 좌표와 범위 입력은 2열로 정렬했습니다.
- 후속 브라우저 확인: 1280×720에서 범위·통계·프로파일을 직접 전환했고, 390×844에서 도구 패널을 열어 세 탭의 Y 좌표와 너비가 동일하며 텍스트 넘침이 없음을 확인했습니다.
- TypeScript/프로덕션 빌드 통과. 기존 번들 크기 경고는 유지.

## 데스크톱 캔버스 중심 수정 결과

사용자 지정에 따라 모바일은 대상에서 제외했습니다. 1280×720 및 1024×768에서 확대·배율·맞춤 오버레이, 표시/통계 패널 열기·닫기, 좌표 조사 및 축이 있는 행/열 프로파일을 확인했습니다. 1024×768에서 캔버스·오버레이·프로파일의 가로 넘침은 없었습니다. X1024/Y1024 결과는 4846 ADU였으며 프로파일에도 같은 값이 표시되었습니다. 두 영상 비교 흐름을 확인하고 좁은 비교 영역에서는 프로파일을 읽을 수 있도록 세로로 배치했습니다. 빌드와 좌표·범위·확대 앵커 관련 검증이 통과했고 브라우저 오류는 없었습니다.
