## 실제 브라우저 동선

검증 전용 폴더와 합성 자료로만 실행합니다. 이 항목은 구현 후 새로 추가하지 않고 발견된 실제 제약·결과를 기록합니다.

1. 빈 작업도에서 task 추가, 동일 task 두 초안 생성, 여러 폴더 입력 선택, 키보드로 입력 연결/해제, 전체/집중/목록 보기 전환.
2. 필요한 master 생성 → 결과 확인 → ccdproc의 정확한 역할에 연결. 상위 재실행 후 하위 버전 유지와 명시적 교체.
3. process=yes 초안에서 같은 패널의 ccdproc·패키지·기기 설정 편집. 다른 초안 불변. 전체 파라미터 검색·기본값 복원·표현식 유지.
4. 헤더 보기 → ccdhedit → 변경 전후 확인 → 선택 입력만 교체 → 원래 초안·선택·작업도 위치 복귀. 영상 A/B·통계 후 복귀.
5. 실행 버튼 자체 검증, 오류 항목 이동, 입력 대기, 대화형 그래픽과 응답/종료/중단, 실행 기록·명령·실효 설정 확인.
6. 1536×1024 승인 시안 비교와 1440px/390px 반응형 검토를 한 번에 수행. 필요한 수정 한 묶음 후 최종 확인 한 번. 키보드 focus, 작은 화면 목록 편집, 긴 파일명·큰 입력 묶음·오류·비어 있음 확인.
