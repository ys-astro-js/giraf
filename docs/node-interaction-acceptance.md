# 노드 UX 인수 확인 — 구현 전 작성

- 결과 하나/여럿/없음: 결과 보기가 오른쪽 결과 탭을 열고 연결 창을 열지 않습니다. 파일 선택은 같은 패널의 미리보기를 바꿉니다. 새 실행 실패 시 이전 성공 결과를 최신 결과로 표시하지 않습니다.
- 출력 클릭 → 목표 카드 클릭: 단일 호환 입력이면 바로 연결됩니다. 여러 입력이면 목표 카드에서 입력만 선택합니다. 출처/목표 재선택 폼은 없습니다.
- 출력 드래그 → 목표 카드 드롭: 클릭 흐름과 같은 규칙입니다. 자기 자신/순환/종류 불일치/여러 출력→단일 입력은 변경 전에 차단됩니다.
- 연결 중 Escape/빈 공간 클릭/취소 버튼: 연결을 만들지 않고 종료합니다. 키보드로 출력·목표·입력을 고를 수 있습니다.
- 기존 입력 교체: 해당 입력만 바뀌고 다른 입력은 보존되며 교체 사실을 알립니다. 비활성 보정 입력은 자동 연결 후보가 아닙니다.
- 카드: 기능 설명·상태·입력별 출처·결과 개수를 읽을 수 있고 입력 역할마다 연결점이 일치합니다.
- 1280×720 및 좁은 화면: 자동 배치 후 카드가 겹치지 않으며 전체 보기에 전체 카드가 포함됩니다. 하단 배율 컨트롤은 카드를 가리지 않습니다. 결과 패널은 독립 스크롤하고 모바일에서는 설정/결과 영역으로 전환됩니다.
- 긴 파일명·텍스트/plot 결과·네트워크 실패: 패널 폭을 넘지 않고 로딩·실패·재시도 경로를 제공합니다.


## 확인 결과

- 회귀 테스트 15개 통과, TypeScript 및 프로덕션 빌드 통과.
- 실제 ccdproc 결과 버튼: 오른쪽 결과 탭, 파일 6개와 영상/텍스트 미리보기 확인. 연결 dialog 없음.
- zerocombine → ccdproc: 출처·목표 고정, 활성 입력 4개를 카드에서 선택하는 상태 확인.
- 임시 imheader: 클릭으로 단일 입력 즉시 연결, darkcombine 출력 드래그로 해당 입력 교체 확인. 임시 노드는 삭제하고 기존 연결 3개를 유지했습니다.
- Enter로 연결 시작 후 Escape로 취소 확인.
- 1280×720 전체 보기: 카드 겹침 0, 캔버스 경계 잘림 0. 390×844: 결과 상세 영역과 캔버스 전환, 가로 문서 넘침 없음.
- 오류·미실행·빈 결과·순환·종류/개수 불일치: 단위/렌더 테스트 확인. 네트워크 실패·plot 미리보기의 실제 브라우저 오류 주입은 수행하지 않았습니다.
