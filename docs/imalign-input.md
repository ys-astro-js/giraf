# imalign 좌표·이동량 입력

## Surface mode

Operate. 사이드바 입력에서 여는 `coords`와 `shifts` 모달은 영상을 보며 별을 지정하는 작업면입니다. 기존 중성색·청록색 토큰과 Base UI 컨트롤을 유지합니다.

## coords

첫 input을 reference로 사용하는 실습 흐름을 따릅니다. 선택 도구를 열면 첫 input을 실제 reference 입력에도 지정합니다. 기준 영상에 현재 좌표를 번호가 붙은 원으로 표시합니다. 옆 표의 번호와 영상의 번호가 대응하며 X/Y를 확인하고 개별 삭제할 수 있습니다. 번호를 선택한 뒤 영상을 클릭하면 해당 좌표를 바꿉니다. 그 외 클릭은 좌표를 추가합니다. 클릭 지점은 IRAF `imexamine`의 `a` 측정을 위한 시작점이며 저장되는 좌표는 측정된 별 중심입니다. 잘못된 좌표 행도 목록에 남겨 삭제하거나 위치를 다시 지정할 수 있습니다.

큰 영상과 폭 208px 좌표 표를 붙여 배치합니다. 좁은 화면에서는 표가 영상 아래로 이동합니다. 번호, X, Y, 삭제 열이 관리 작업의 기본 구조이며 반복 사용법이나 개수 제목을 추가하지 않습니다.

## shifts

기준 영상과 입력 영상을 연속된 비교 그리드에 표시합니다. 데스크톱은 최대 4열, 중간 폭은 3열, 좁은 화면도 2열을 유지합니다. 영상 사이는 1px 구분선만 사용하며 각 파일명과 이동량은 얇은 행에 표시합니다. 많은 영상은 그리드 내부에서 스크롤합니다.

기준별은 coords와 독립적으로 선택하되 영상은 첫 input과 동일합니다. 기준 영상에서 한 별을 찍은 후 각 입력 영상의 같은 별을 찍으면 입력 순서대로 이동량이 갱신됩니다. 기준점을 다시 찍으면 이미 선택한 입력 별의 이동량도 다시 계산합니다. 부호는 `ΔX = 기준 X − 입력 X`, `ΔY = 기준 Y − 입력 Y`입니다. 첫 input은 기준점과 동일한 측정 좌표를 공유합니다. 모든 행에 같은 차분식을 적용하므로 첫 행은 자기 자신과의 차이로 `0 0`이 됩니다. 상수를 대입하거나 첫 행만 사후 보정하지 않습니다. 나머지 영상도 IRAF `imexamine a`의 소수점 중심 좌표를 측정합니다. 선택 전 행은 `? ?`입니다.

영상 위 별 표시는 각 영상당 하나입니다. 입력 영상의 별은 다시 찍거나 개별 삭제할 수 있습니다. 상단의 공통 확대·축소·맞춤과 각 영상의 휠·드래그는 모든 영상에 적용됩니다. 이동 오프셋은 뷰포트 크기에 비례해 공유합니다. 마우스 환경에서 개별 표시 설정과 좌표 입력 도구는 해당 영상에 포인터나 키보드 초점이 있을 때 표시합니다.

## 공통 규칙

모달 제목은 파라미터명입니다. 사용법 문장, 반복되는 미선택 상태 문장, 장식용 배지, 영상마다 반복하는 확대 도구는 표시하지 않습니다. 선택 값은 즉시 입력에 반영되며 완료는 모달을 닫습니다. 전체 비우기는 휴지통 아이콘과 접근 가능한 이름으로 제공합니다.

직접 입력과 기존 파일 입력, 영상 입력 변경 시 확인 절차는 유지합니다. 영상에서 선택하려면 개별 파일이나 완료된 실행 결과가 필요합니다. 별 선택 시 중심 측정과 실행 시 실제 정렬 모두 IRAF가 수행합니다. 측정 실패 시 클릭 좌표로 대체하지 않고 오류를 표시합니다.
