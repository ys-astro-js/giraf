# imalign 좌표·이동량 입력

`images.immatch.imalign`의 입력 영역에서 기준별 좌표와 초기 이동량을 준비합니다. 기존 작업 탐색·입력·실행 흐름과 [디자인 시스템](../DESIGN.md)을 유지하는 국소 확장입니다.

## 입력과 선택

- **기준별 좌표**는 `coords`, **초기 이동량**은 `shifts`를 보조 식별자로 표시합니다. 각 필드는 **직접 입력**과 **기존 입력** 탭을 사용합니다.
- 좌표는 한 행에 `X Y`를 입력하며 1부터 시작합니다. 기준 영상을 지정하면 **영상에서 별 선택**으로 기존 영상 뷰어를 열고 선택한 좌표를 행으로 추가합니다.
- 이동량은 입력 영상 순서대로 한 행에 `ΔX ΔY`를 입력합니다. **같은 별로 이동량 계산**은 직접 입력한 첫 번째 기준별과 각 입력 영상의 같은 별을 사용합니다. 부호는 `ΔX = 기준 X − 입력 X`, `ΔY = 기준 Y − 입력 Y`입니다.
- 이동량 선택 후 다음 입력 영상으로 이동하며, 아직 선택하지 않은 행은 `? ?`로 남습니다. 모든 행을 채우거나 이동량 전체를 비웁니다. 전체가 비어 있으면 초기 이동량 추정은 IRAF가 수행합니다.
- 기존 파일 입력은 유지합니다. 직접 입력 내용이 남아 있는 상태에서 **기존 입력**으로 전환하면 이를 비우는 동작을 먼저 표시합니다.
- 별 선택 창은 즉시 입력 값을 갱신합니다. **완료**는 창을 닫으며, **마지막 행 지우기**는 입력의 마지막 행을 삭제합니다.
- 기준 영상이나 이동량에 대응하는 입력 영상 순서가 달라지면 확인 안내와 **현재 영상 기준으로 확인 완료** 동작을 표시합니다.

영상 선택에는 개별 파일 또는 실행 완료한 영상 결과가 필요합니다. 표현식이나 미실행 노드 입력은 파일 선택 또는 실행 결과로 지정하거나 직접 수치·기존 파일 입력을 사용합니다. 이 화면은 별 위치를 정렬 입력으로 전달하며, 실제 정렬과 중심 측정은 IRAF가 수행합니다.

## 시각·상태 규칙

기존 Base UI 필드·탭·대화상자·버튼과 영상 뷰어를 재사용합니다. 중성색 작업면과 청록색 완료 동작, 한국어 주 라벨과 IRAF 보조 식별자, 일반 텍스트 선택 개수를 유지합니다. 새 색상·글꼴·곡률 토큰은 없습니다.

설명과 오류는 관련 필드 가까이에 둡니다. 수치 형식 오류에는 텍스트와 `aria-invalid`를 함께 사용하며, 오류는 alert, 선택 결과는 status로 알립니다. 기준 영상이 없거나 이동량 계산에 필요한 기준 좌표·입력 영상이 없으면 선택 버튼을 비활성화합니다.

선택 창은 화면 높이의 90% 이내에서 스크롤하고, 영상 영역 높이는 화면 높이의 44%와 440px 중 작은 값입니다. 이는 이 선택 창에만 적용되는 배치이며 전역 영상 뷰어 규칙을 변경하지 않습니다.

## 확인 근거

- 구현: `web/src/components/alignment-input.tsx`, `web/src/components/task-inspector.tsx`, `web/src/lib/alignment.ts`, `web/src/index.css`.
- 제공된 [데스크톱 화면](../.impeccable/review/imalign-desktop.png)과 [모바일 화면](../.impeccable/review/imalign-mobile.png)에서 기준 영상 선택 창의 한국어 안내, 영상, 좌표 입력, 확대 도구, 선택 개수, 삭제·완료 동작이 화면 안에 표시되는 것을 확인했습니다.
- 화면 캡처는 밝은 테마의 기준별 선택 상태를 보여 줍니다. 이동량 선택·키보드 동작·어두운 테마의 실행 검증까지 입증하는 자료는 아닙니다.

기존 시각 체계와 일치하는 국소 확장으로 판단했습니다. 전역 `DESIGN.md`와 디자인 sidecar를 재생성할 새로운 시스템 결정은 없습니다.
